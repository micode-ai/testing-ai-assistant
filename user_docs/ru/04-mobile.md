# Мобильное приложение

## Обзор

Мобильное приложение Testing AI Assistant построено на Expo 52 и React Native 0.76.5. Оно поддерживает iOS и Android и предоставляет доступ к основным функциям платформы на ходу.

## Системные требования

| Компонент | Требование |
|-----------|-----------|
| Node.js | >= 20.0.0 |
| Expo CLI | Устанавливается через `npx` |
| iOS | Xcode 15+ (для iOS-разработки) |
| Android | Android Studio + SDK 34+ |
| Expo Go | Для быстрого тестирования на устройстве |

## Установка и запуск

### Локальная разработка

```bash
cd apps/mobile
npm install

# Запуск Expo dev-сервера
npm start

# Запуск на Android
npm run android

# Запуск на iOS
npm run ios

# Запуск в браузере
npm run web
```

### Тестирование на устройстве

1. Установите **Expo Go** на мобильное устройство (App Store / Google Play)
2. Запустите `npm start` в директории `apps/mobile`
3. Сканируйте QR-код из терминала камерой устройства
4. Приложение откроется в Expo Go

## Функциональность

### Аутентификация

- Вход по email и паролю
- OAuth-вход через GitHub, GitLab, Bitbucket
- Безопасное хранение токенов через `expo-secure-store`
- Автоматическое обновление токенов

### Основные экраны

- **Главная** — обзор текущего состояния: активные прогоны, недавние результаты
- **Организации** — просмотр и переключение между организациями
- **Проекты** — список проектов, статус вебхуков
- **Пайплайны** — просмотр и запуск пайплайнов
- **Тестовые прогоны** — отслеживание выполнения, просмотр результатов
- **AI-генерация** — запуск и просмотр AI-генераций
- **Уведомления** — push-уведомления о событиях

### Push-уведомления

Приложение поддерживает push-уведомления через `expo-notifications`:

- Завершение тестовых прогонов
- Обнаружение сбоев
- Приглашения в организации
- Результаты AI-генерации

### Навигация

Приложение использует `expo-router` (файловая маршрутизация):

- Табы для основных разделов
- Stack-навигация для деталей
- Deep linking для прямого перехода
