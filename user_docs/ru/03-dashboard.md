# Веб-панель (Dashboard)

## Обзор

Dashboard — это веб-приложение на базе Next.js 15 с React 19, предоставляющее полный интерфейс для управления тестированием. Доступ по адресу: **http://localhost:4200**.

## Аутентификация

### Регистрация

1. Откройте http://localhost:4200
2. Нажмите «Зарегистрироваться»
3. Заполните форму: имя, email, пароль
4. Подтвердите регистрацию

### Вход

- **По email и паролю** — стандартный вход
- **Через OAuth** — кнопки GitHub, GitLab, Bitbucket (если настроены)

После входа вы получите JWT-токен, который автоматически обновляется через refresh-токен.

### Выход

Нажмите на аватар в правом верхнем углу и выберите «Выйти». Токен будет отозван и добавлен в чёрный список.

## Главные разделы

### Организации

- **Список организаций** — все организации, в которых вы участвуете
- **Создание организации** — кнопка «Новая организация»
- **Настройки организации** — редактирование названия, описания
- **Управление участниками** — приглашение, одобрение, назначение ролей

### Проекты

- **Список проектов** — проекты в рамках выбранной организации
- **Создание проекта** — указание имени, описания, Git-репозитория
- **Подключение вебхука** — автоматический запуск тестов по push/PR
- **Настройки проекта** — редактирование параметров, отключение вебхука

### Пайплайны

- **Список пайплайнов** — все пайплайны проекта
- **Создание пайплайна** — выбор типов тестов, настройка параметров
- **Включение/отключение** — переключатель активности пайплайна
- **Детали пайплайна** — история прогонов, конфигурация

### Тестовые прогоны

- **Список прогонов** — все запуски тестов для пайплайна
- **Запуск вручную** — кнопка «Запустить»
- **Отмена прогона** — остановка выполнения
- **Детали прогона** — результаты по каждому тесту, логи, время выполнения
- **Обновления в реальном времени** — SSE для отображения прогресса

### AI-генерация

- **Запуск генерации** — выбор типа: генерация тестов, поиск багов, flaky-тесты, покрытие
- **Список генераций** — история всех AI-генераций
- **Детали генерации** — сгенерированный код, объяснения
- **Обратная связь** — принять или отклонить результат с комментарием
- **Статистика** — общая аналитика по AI-генерациям

### AI Чат

- **Интерфейс чата** — разговорный AI-ассистент для каждого проекта
- **Вызов инструментов** — AI может создавать чек-листы, запускать пайплайны, просматривать результаты
- **База знаний** — отвечает на вопросы с использованием проиндексированной документации (RAG)
- **История диалогов** — прошлые чаты сохраняются и доступны из боковой панели
- **Потоковые ответы** — отображение ответа в реальном времени, посимвольно

### Чек-листы

- **Генерация с ИИ** — кнопка «Сгенерировать с ИИ» создаёт чек-лист через ChecklistGeneratorAgent с автоматической разбивкой на секции
- **Секции** — пункты чек-листа группируются в сворачиваемые секции (поле `section`)
- **Чекбоксы** — отметка выполнения каждого пункта (`isCompleted`)
- **Заметки** — текстовые заметки к каждому пункту (`note`), с отслеживанием времени обновления (`noteUpdatedAt`)
- **AI-чат по пункту** — для каждого пункта доступен отдельный AI-чат (тип `CHECKLIST_ITEM_CHAT`), сообщения хранятся в pipeline DB (модель `ChecklistItemMessage`)

### Покрытие кода

- **Снимки покрытия** — отображение процента покрытия по прогонам
- **Тренды** — графики изменения покрытия во времени

### Уведомления

- **Конфигурации** — настройка каналов уведомлений
- **История** — список отправленных уведомлений

## Навигация

Боковое меню имеет многоуровневую структуру, которая адаптируется к текущему контексту:

**Tier 0** — отображается всегда:
1. **Главная** — обзор и быстрые действия
2. **Организации** — управление организациями

**Tier 1** — появляется при выбранной организации:
3. **Проекты** — управление проектами
4. **Запуски** — тестовые прогоны

**Tier 2** — появляется при выбранном проекте:
5. **AI Чат** — AI чат-ассистент
6. **Пайплайны** — тестовые пайплайны
7. **Покрытие** — отчёты о покрытии кода
8. **Чек-листы** — тестовые чек-листы
9. **ИИ Хаб** — AI-генерация и анализ

Переключатель организации (OrgSwitcher) в боковом меню при выборе организации навигирует на страницу проектов (`/projects`). Рядом с переключателем доступна иконка настроек организации.

### Карточки организаций

При клике на карточку организации открывается её детальная страница (`/organizations/{id}`). Дополнительные ссылки на карточке:
- Количество участников ведёт на `/organizations/{id}/members`
- Кнопка настроек ведёт на `/organizations/{id}/settings`

## Подсказки

- Используйте фильтры и поиск для навигации по большим спискам
- SSE-обновления работают автоматически — страницу не нужно обновлять вручную
- Для мобильного доступа используйте приложение Expo (см. [Мобильное приложение](./04-mobile.md))
