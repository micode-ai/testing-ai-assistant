# Организации и проекты

## Организации

Организация — это верхнеуровневая единица группировки в Testing AI Assistant. Все проекты, пайплайны и настройки существуют в рамках организации.

### Создание организации

1. Перейдите в раздел «Организации»
2. Нажмите «Новая организация»
3. Укажите название и описание
4. Нажмите «Создать»

Вы автоматически становитесь администратором созданной организации.

### Роли участников

| Роль | Описание | Права |
|------|----------|-------|
| `ADMIN` | Администратор | Полный доступ: управление участниками, проектами, настройками |
| `MEMBER` | Участник | Создание и управление проектами, запуск тестов |
| `VIEWER` | Наблюдатель | Только просмотр проектов и результатов |

### Управление участниками

#### Приглашение

1. Откройте организацию → «Участники»
2. Нажмите «Пригласить»
3. Укажите email пользователя и роль
4. Приглашение отправляется на email

#### Одобрение / Отклонение

Администраторы могут одобрять или отклонять запросы на вступление:

1. Откройте раздел «Ожидающие» в списке участников
2. Нажмите «Одобрить» или «Отклонить»

#### Изменение роли

1. Откройте список участников
2. Найдите участника
3. Выберите новую роль из выпадающего списка

#### Удаление участника

1. Откройте список участников
2. Нажмите «Удалить» рядом с участником
3. Подтвердите действие

### API организаций

```
POST   /organizations/:orgId/members/invite         — Приглашение участника
GET    /organizations/:orgId/members                 — Список участников
PATCH  /organizations/:orgId/members/:id/approve     — Одобрение
PATCH  /organizations/:orgId/members/:id/reject      — Отклонение
PATCH  /organizations/:orgId/members/:id/role        — Изменение роли
DELETE /organizations/:orgId/members/:id             — Удаление
```

## Проекты

Проект привязан к организации и представляет собой Git-репозиторий, для которого настраивается автоматическое тестирование.

### Создание проекта

1. Перейдите в организацию → «Проекты»
2. Нажмите «Новый проект»
3. Заполните:
   - **Название** — имя проекта
   - **Описание** — краткое описание
   - **Git-провайдер** — GitHub, GitLab или Bitbucket
   - **URL репозитория** — ссылка на репозиторий
   - **Ветка по умолчанию** — основная ветка (например, `main`)
4. Нажмите «Создать»

### Подключение вебхука

Вебхук позволяет автоматически запускать тесты при push или pull request.

1. Откройте проект → «Настройки»
2. Нажмите «Подключить вебхук»
3. Система автоматически создаст вебхук в Git-провайдере
4. Статус отобразится как «Подключён»

> **Важно:** Для создания вебхука необходимы права администратора репозитория и настроенные OAuth-токены Git-провайдера.

### Отключение вебхука

1. Откройте проект → «Настройки»
2. Нажмите «Отключить вебхук»
3. Вебхук будет удалён из Git-провайдера

### Обработка событий вебхука

При получении события от Git-провайдера система:

1. Проверяет подпись и валидность события
2. Определяет тип события (push, pull request)
3. Находит подходящие активные пайплайны
4. Автоматически запускает тестовые прогоны

### API проектов

```
POST   /projects                           — Создание проекта
GET    /projects?orgId=<id>                — Список проектов
GET    /projects/:id                       — Детали проекта
PATCH  /projects/:id                       — Обновление
DELETE /projects/:id                       — Удаление
POST   /projects/:id/webhook/connect       — Подключение вебхука
DELETE /projects/:id/webhook/disconnect    — Отключение вебхука
```

## Git-провайдеры

### Поддерживаемые провайдеры

| Провайдер | OAuth | Вебхуки | Статус |
|-----------|-------|---------|--------|
| GitHub | Да | Да | Полная поддержка |
| GitLab | Да | Да | Полная поддержка |
| Bitbucket | Да | Да | Полная поддержка |

### Настройка OAuth

Для интеграции с Git-провайдером настройте OAuth-приложение и укажите ключи в `.env`:

**GitHub:**
```env
GITHUB_CLIENT_ID=ваш-client-id
GITHUB_CLIENT_SECRET=ваш-client-secret
```

**GitLab:**
```env
GITLAB_CLIENT_ID=ваш-client-id
GITLAB_CLIENT_SECRET=ваш-client-secret
```

**Bitbucket:**
```env
BITBUCKET_CLIENT_ID=ваш-client-id
BITBUCKET_CLIENT_SECRET=ваш-client-secret
```
